# HackAlem AI — Event Match

Адаптивный фронтенд для подбора event-подрядчиков в Казахстане. Совместим с FastAPI из ветки `backend-python`, предоставленным в архиве `hack-7abc9233-gamedev.zip`.

Пользователь задаёт параметры мероприятия и получает до трёх профилей с объяснениями. Подбор выполняет сервер; в HTML не встроены демоданные или ключи доступа.

## Что обновлено

- API: `POST http://localhost:8000/recommend`.
- В запросе используются `event_date` и `budget`.
- Карточки читаются из `results`, имя — из `name`, цена — из `price`.
- Добавлены необязательные язык и длительность.
- Различаются отсутствие категории в городе и отсутствие совпадений по условиям.
- Показываются сообщения сервера, число найденных вариантов и признаки подготовки данных.
- Фронтенд запускается на порту **5173**, уже разрешённом в CORS бэкенда друга.

## Добавление к проекту друга

1. Положите обновлённые `index.html` и `README.md` в корень общего проекта, рядом с папкой `backend/`.
2. Сохраните `backend/`, `.gitignore` и `.env.example` из проекта бэкенда. Его инструкция находится в `backend/README.md`.
3. Используйте Git-историю своего рабочего репозитория. Не копируйте `.git` из другого ZIP поверх своей.
4. Создайте новое виртуальное окружение по инструкции ниже. Готовая Windows-папка `.venv` из архива друга не требуется.

Изменять Python-код предоставленного бэкенда для этой версии фронтенда не нужно.

## Запуск на Windows

Нужен установленный Python 3.10 или новее. Откройте общую папку проекта в VS Code.

### Терминал 1 — бэкенд

При первой установке:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
```

Запуск:

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```

Проверка: [http://localhost:8000/health](http://localhost:8000/health) должен вернуть `status: "ok"` и `profiles: 66`. Документация API: [http://localhost:8000/docs](http://localhost:8000/docs).

### Терминал 2 — фронтенд

В корне того же проекта:

```powershell
py -m http.server 5173 --bind 127.0.0.1
```

Откройте **[http://localhost:5173](http://localhost:5173)**. Оба терминала должны оставаться запущенными. Если команда `py` недоступна, используйте `python` вашей установки.

Прямое открытие HTML через `file://` подходит для просмотра оформления. Для подбора используйте HTTP-адрес выше: бэкенд по умолчанию не разрешает origin `null` локального файла.

## CORS и адрес сервера

В предоставленном бэкенде уже разрешены `http://localhost:5173` и `http://127.0.0.1:5173`. При таком запуске правки CORS не нужны.

Если в окружении или `.env` уже задана переменная `CORS_ORIGINS`, она заменяет значения по умолчанию. Убедитесь, что в ней есть адрес открытой страницы. Для другого порта задайте полный список origin, например:

```dotenv
CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173,http://localhost:5500
```

После изменения настроек перезапустите бэкенд. Документация: [FastAPI CORS](https://fastapi.tiangolo.com/tutorial/cors/).

Адрес запросов меняется в одном месте в `index.html`:

```javascript
const API_URL = 'http://localhost:8000/recommend';
```

Для размещения в интернете укажите публичный HTTPS-адрес бэкенда с `/recommend` и разрешите origin сайта в CORS. `localhost` в браузере означает компьютер посетителя. Публикация одного HTML не запускает Python-бэкенд.

## Контракт API

### Запрос

`POST /recommend`, `Content-Type: application/json`.

```json
{
  "city": "Астана",
  "event_date": "2026-10-15",
  "event_type": "свадьба",
  "category": "Ведущий",
  "budget": 900000,
  "duration": 6,
  "language": "казахский"
}
```

| Поле | Правило |
| --- | --- |
| `city` | Алматы, Астана или Зарубежье |
| `event_date` | `YYYY-MM-DD`, с 2026-09-23 по 2026-12-31 |
| `event_type` | В нижнем регистре, например `свадьба` |
| `category` | Одна категория из формы |
| `budget` | Целое число тенге, не меньше нуля; бюджет на одного подрядчика |
| `duration` | Необязательное положительное число часов; допустимы дробные значения |
| `language` | Необязательный язык: казахский, русский или английский |

Пустая длительность и вариант «Любой язык» означают отсутствие этих полей в запросе. Неизвестные ключи запрещены моделью бэкенда. Внешний вид поля даты зависит от языка браузера, но в JSON отправляется ISO-дата.

### Ответ

Пример структуры с условным подрядчиком:

```json
{
  "status": "matches_found",
  "count": 1,
  "results": [
    {
      "id": "DEMO-001",
      "name": "Пример подрядчика",
      "category": "Ведущий",
      "city": "Астана",
      "price": 450000,
      "explanation": "Объяснение соответствия параметрам, сформированное бэкендом.",
      "synthetic": false,
      "city_imputed": false,
      "price_imputed": false
    }
  ],
  "message": "Подходит 1; показан 1.",
  "total_candidates": 1,
  "total_matches": 1,
  "exclusion_counts": {}
}
```

| `status` | Отображение |
| --- | --- |
| `matches_found` | Карточки и количество показанных вариантов |
| `no_category_in_city` | Предложение изменить город или категорию |
| `no_matches` | Предложение изменить дату, бюджет или дополнительные фильтры |

Для двух последних состояний `results` должен быть пустым массивом. Фронтенд сохраняет порядок сервера и выводит максимум три карточки. Показывает `message` и, если передано, дополнительное поле `status_message`.

Признаки `synthetic`, `city_imputed`, `price_imputed` отмечаются в карточках, когда равны `true`. Цена означает «от»; итоговая стоимость может отличаться. Серверный текст вставляется через `textContent` без выполнения HTML.

Форма блокируется на время запроса. Таймаут — 45 секунд. При ошибке доступна повторная попытка. При изменении параметров старая подборка очищается.

## Сценарии проверки

| Сценарий | Параметры | Результат на предоставленном CSV |
| --- | --- | --- |
| Пустая подборка | Алматы, 2026-10-15, свадьба, ведущий, 500000 ₸; дополнительные поля пустые | Нет совпадений |
| Три профиля | Те же параметры, бюджет 900000 ₸ | Мицури Канроджи, Эмилия и Кики; порядок задаёт сервер |
| Дополнительные фильтры | Астана, 2026-10-15, свадьба, ведущий, 900000 ₸, казахский, 6 ч | Есть Санджи Виндсмок (`HK-80581`) |
| Проверка занятости | Предыдущий запрос, дата 2026-10-16 | Санджи Виндсмок исключён |
| Категории нет в городе | Зарубежье, ведущий | `no_category_in_city` |
| Ошибка подключения | Остановить бэкенд и нажать «Подобрать» | Сообщение об ошибке и кнопка повтора |

Проверено в Chromium с реальным неизменённым FastAPI из архива друга и его CSV: CORS на порту 5173, поля запросов, язык и длительность, доступность на разных датах, пустые результаты и карточки. Проверены ширины экрана 320, 390, 768 и 1440 пикселей. Ошибка HTTP 422 и повторная попытка дополнительно проверены с контролируемым ответом.

## Состояние ИИ-части

Предоставленный `backend/ranking.py` сортирует прошедшие фильтры профили по признакам подготовки данных и ID, а объяснения собирает из шаблона. `/recommend` пока не вызывает внешнюю модель. `openai_client.py` содержит заготовку для дальнейшего подключения ИИ.

В интерфейсе используется формулировка «Подбор с объяснением». Для текущего запуска API-ключ не требуется. После подключения модели на сервере можно сохранить контракт API — фронтенд продолжит отображать `explanation`.
